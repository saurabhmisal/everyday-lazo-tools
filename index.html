Set up your workspace

01

Get Everyday

Sign up and verify your email. Download the Apple Silicon preview.

02

Choose your data folder

Set a recovery password, then select Choose folder & start. Use a local drive. Keep the password in your password manager.

03

Keep a recovery copy

Save encrypted backup to another drive. Copy linked files and external notes separately.

Reinstalling Everyday?

Reinstall the app, choose Open existing data folder and select your original data folder.

If you deleted that folder too, choose Restore backup file and enter your backup password.
Reconnecting sources brings back accessible originals. Everyday-only tasks, drafts and focus history require the folder or a backup.
